# Jain Chaat Bhandar — Website

A one-page website for Jain Chaat Bhandar, a much-loved pure-veg Jain chaat shop at Novelty Chauraha, Lalbagh, Lucknow, serving Jain Chaat, Aloo Tikki, Matar Tikki, Papdi Chaat and Dahi Vade — prepared without onion and garlic.

- Address: Naval Kishore Road, Novelty Chauraha, Lalbagh, Lucknow
- Phone: +91 96287 44871
- Hours: Daily 4:00 PM – 10:00 PM

Built as a single static `index.html` (Tailwind via CDN). Details are taken from public listings (Justdial, Google Places) and can be updated by the owner at any time.
